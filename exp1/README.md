## 📖 Aim

To develop a React-based Post Composer application that allows users to create and preview social media posts using reusable components and form handling.

---

## 📌 Description

This project demonstrates the fundamentals of React by building a simple social media post composer. Users can enter a title, content, select a platform, and preview their post through an interactive and responsive interface.

The application focuses on component-based architecture, state management using React Hooks, and form validation.

---

## ✨ Features

- Create social media posts
- Select publishing platform
- Live post preview
- Form validation
- Responsive design
- Clean and modern UI

---
