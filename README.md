## 📖 About

This repository contains my **Full Stack Development II (FSD-II)** laboratory experiments completed during **Semester 5** of my Bachelor of Engineering in Computer Science.

Each experiment demonstrates a different concept in modern web development using **React**, **Redux Toolkit**, **JWT Authentication**, and related technologies.

---

## 📂 Repository Structure

### 📌 Experiment 1 – Post Composer
A React application for composing and scheduling social media posts with form validation and a responsive interface.

**Topics Covered**
- React Components
- Forms and Validation
- State Management
- Responsive UI

---

### 📌 Experiment 2 – Social Media Scheduler
A complete social media scheduling dashboard built using React and Redux Toolkit.

**Features**
- Create, edit and delete posts
- Draft, Scheduled and Published workflow
- Monthly Calendar
- Platform Analytics
- Search & Filtering
- Redux Toolkit State Management
- Responsive Dashboard

---

### 📌 Experiment 3 – JWT Authentication
A React application demonstrating JWT (JSON Web Token) based authentication and protected routes.

**Topics Covered**
- JWT Authentication
- Login System
- Protected Routes
- API Integration
- Authentication Flow
