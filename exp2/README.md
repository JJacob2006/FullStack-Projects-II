## 📖 Aim

To design and develop a Social Media Scheduler using React and Redux Toolkit that allows users to create, manage, schedule, and publish posts while visualizing analytics through an interactive dashboard.

---

## 📌 Description

The Social Media Scheduler is a complete React-based dashboard developed as part of the Full Stack Development-II laboratory.

The application allows users to manage social media content across multiple platforms by creating drafts, scheduling posts, publishing content, and monitoring analytics through a modern dashboard interface.

Redux Toolkit is used for centralized state management, while reusable React components ensure a modular and maintainable architecture.
